# UI Registry

Reusable web UI patterns. Updated via `/imprint` after each new reusable component.

## Primitives (shadcn)
- Button (variants: primary, secondary, ghost, danger)
- Input, Textarea, Select, Checkbox, Switch
- Table (sortable, paginated)
- Dialog (confirmation + form)
- Tabs, Card, Badge, Avatar
- Toast (notifications)
- DatePicker, MultiSelect (tags)

## Composite patterns
- PageHeader: title + actions + branch filter (conditional)
- StatsCard: label, value, trend
- EmptyState: icon, message, action
- DataTable: columns config + server pagination + row actions
- ApprovalRow: item summary + approve/reject
- AuditRow: actor, action, entity, time, diff

## Mobile (Expo) equivalents
- ScreenShell: header + scroll body + bottom tabs
- ProfileField (read/edit)
- ClockButton (in/out)
- PayslipCard
- LeaveRequestForm
- NotificationItem
